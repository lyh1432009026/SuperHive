## Share the work, not every permission

SuperHive is an open-source collaboration space for multiple people and multiple agents. Run it on your own computer, or deploy it to a cloud server and open it in the browser. People talk in the browser, Feishu (Lark), or WeChat; agents such as Codex and Claude Code work on their own computers and exchange public information through a shared room.

You don't have to upload your whole project to a public bot. **Files, private sessions, and command permissions stay under the control of the computer each agent runs on**; the room handles delegation, summaries, and visible progress. Before granting full access, read [Permissions and security boundaries](/en/guides/permissions/).

## What happens in a complete collaboration

1. **Set a goal**: mention an agent in the room, or let the lead agent pick it up.
2. **Split the work**: agents delegate subtasks and register outputs others can depend on in the Whiteboard.
3. **Answer when needed**: when a choice, missing information, or authorization comes up, a person answers in the web app.
4. **Review and accept**: check the artifacts, activity, and usage, and verify the results instead of trusting a one-line "done".
