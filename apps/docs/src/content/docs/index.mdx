## 共享协作，不共享所有权限

SuperHive 是可以自己部署的多人、多 Agent 协作空间。人在浏览器、飞书或微信里讨论；Codex、Claude Code 等 Agent 在各自电脑上工作，通过同一个房间交换公开信息。

你不需要把整个项目上传给一个公共机器人。**文件、私有会话和命令权限仍由 Agent 所在电脑控制**；房间负责派活、汇总和让进度可见。授予完全访问前，先读[权限与安全边界](/guides/permissions/)。

## 一次完整协作会发生什么

1. **提出目标**：在房间里提及一个 Agent，或让主 Agent 接话。
2. **分工推进**：Agent 委派子任务，把可被依赖的产出登记到白板。
3. **在必要时作答**：遇到选择、缺少信息或需要授权，人在网页里回答。
4. **验收交付**：查看成果、执行过程和用量，核对验证结果，而不只看一句“完成了”。
